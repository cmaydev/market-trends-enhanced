# market-trends-enhanced

This is a React web app that analyzes and visualizes market trends using AI.

## 🧪 Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/cmaydev/market-trends-enhanced.git
   cd market-trends-enhanced
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm start
   ```

## 🚀 Deployment

Build for production:
```bash
npm run build
```

## 🛠 Built With

- React
- Node.js
- OpenAI API
- Tailwind CSS
